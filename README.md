# Webmapping, Master SIGMA

Espace de questions et de rendus de l'UE902-1 Webmapping, pour les séances 3 et 4 faites en
autonomie. Les supports sont sur le site du cours :
[le parcours en autonomie](https://nicolaslagarrigue.fr/sigma/web/902-1-autonomie/).

## Poser une question

Dans l'onglet **Discussions**, catégorie **Questions** :

1. Cherchez d'abord si la question a déjà été posée : la réponse vous attend peut-être.
2. Un titre qui dit le problème (« Les cercles ne s'affichent pas à l'étape 10 », pas « Aide »).
3. Dans le message :
    - ce que vous avez fait (l'étape, le fichier) ;
    - ce que vous attendiez ;
    - ce que vous voyez, avec le message de la console du navigateur copié tel quel ;
    - le code en cause, entre deux lignes de trois accents graves :

    ````
    ```js
    map.addLayer({ ... });
    ```
    ````

Quand une réponse règle votre problème, marquez-la comme réponse (*Mark as answer*) : elle servira
aux suivants. Vous pouvez aussi répondre aux questions des autres.

## Rendre le TP

Dans l'onglet **Discussions**, catégorie **Annonces**, la discussion **Rendus du TP « Le portrait des
communes du Parc »** : un commentaire avec vos deux adresses, la carte publiée sur GitHub Pages et le
dépôt GitHub.
